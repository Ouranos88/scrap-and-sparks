# Scrap & Sparks

A story game that teaches n8n from zero. Every mission is a real workflow you build in your own n8n, on your computer, and the game checks it. Chapters 1 to 6 are free.

**Website, install guide and demo:** https://scrap-and-sparks-dnk.pages.dev

## Install

1. Install Docker (the [install guide](https://scrap-and-sparks-dnk.pages.dev/install/) shows how, for Windows, Mac and Linux).
2. Download **[scrap-and-sparks.zip](https://github.com/Ouranos88/scrap-and-sparks/releases/latest/download/scrap-and-sparks.zip)** and unzip it.
3. Start it: `start.bat` (Windows, double-click) or `sh start.sh` (Mac, Linux).

The first start downloads n8n and the game (about 4 GB), then the game opens at http://localhost:8765 on Level 0, which guides you from there. Stop it with `stop.bat` or `sh stop.sh`; your progress and your n8n stay saved.

This repository holds only these starter files. The game runs from a prebuilt image, `ghcr.io/ouranos88/scrap-and-sparks-companion`, next to n8n's official images. Everything listens on your own computer only (127.0.0.1).

Feedback: https://scrap-and-sparks-dnk.pages.dev/feedback/
