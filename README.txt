Scrap & Sparks: a story game that teaches n8n
https://scrap-and-sparks-dnk.pages.dev

You need Docker first (the install guide on the website shows how).

Windows : double-click start.bat
Mac     : in Terminal, type "sh " then drag start.sh into the window, press Enter
Linux   : sh start.sh

The first start downloads n8n and the game (about 4 GB). Then the game opens in your
browser at http://localhost:8765 on Level 0, which guides you from there.

To stop: stop.bat (Windows) or sh stop.sh (Mac, Linux). Your progress and your n8n stay saved.
Keep the .env file that start creates: it holds a private key for your n8n.

Scrap & Sparks is an unofficial game. It is not affiliated with or endorsed by n8n.
