Scrap & Sparks: a story game that teaches n8n
https://scrap-and-sparks-dnk.pages.dev

Easiest: the one-file installers on the website install Docker and the game for you.
With this folder, you need Docker first (the install guide on the website shows how).

Windows : double-click start.bat
Mac     : double-click start.command. The first time, macOS blocks it (it is not signed):
          open System Settings > Privacy & Security, click "Open Anyway", then double-click again.
Linux   : sh start.sh

The first start downloads n8n and the game (about 4 GB). Then the game opens in your
browser at http://localhost:8765 on Level 0, which guides you from there.

To stop: stop.bat (Windows), stop.command (Mac) or sh stop.sh (Linux). Your progress and your n8n stay saved.
Keep the .env file that start creates: it holds a private key for your n8n.

Scrap & Sparks is an unofficial game. It is not affiliated with or endorsed by n8n.

Scrap & Sparks : un jeu à histoire pour apprendre n8n
https://scrap-and-sparks-dnk.pages.dev/fr/

Le plus simple : les installateurs en un fichier du site installent Docker et le jeu pour toi.
Avec ce dossier, il te faut d'abord Docker (le guide d'installation sur le site montre comment).

Windows : double-clique sur start.bat
Mac     : double-clique sur start.command. La première fois, macOS le bloque (il n'est pas signé) :
          ouvre Réglages Système > Confidentialité et sécurité, clique sur « Ouvrir quand même »,
          puis double-clique à nouveau.
Linux   : sh start.sh

Le premier démarrage télécharge n8n et le jeu (environ 4 Go). Ensuite le jeu s'ouvre dans ton
navigateur à l'adresse http://localhost:8765 sur le niveau 0, qui te guide à partir de là.

Pour arrêter : stop.bat (Windows), stop.command (Mac) ou sh stop.sh (Linux). Ta progression et ton n8n restent
enregistrés. Garde le fichier .env créé au démarrage : il contient une clé privée pour ton n8n.

Scrap & Sparks est un jeu non officiel. Il n'a aucun lien avec n8n et n'est pas approuvé par n8n.
